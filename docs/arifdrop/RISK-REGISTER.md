# ArifDrop Technical Risk Register

**Project**: ArifDrop (Gumroad fork for Ethiopia)  
**Date**: October 2026  
**Auditor**: Antigravity Assistant  
**Repository Baseline**: `antiwork/gumroad` (`cc4d616c7`)

---

## 1. Overview

This risk register identifies concrete architectural, operational, and integration risks discovered in the Gumroad codebase during the ArifDrop audit. Each item is grounded in verified code locations and outlines the exact impact, likelihood, verification requirements, and project phase.

_Note: Per audit guidelines, an aggregate product score is omitted._

---

## 2. Risk Matrix

| #        | Risk Description                                          | Code Evidence                                                                                                                                                                                                                                          | Impact                                                                                                                                            | Likelihood  | What Must Be Verified                                                                                                                                                 | Phase                   |
| :------- | :-------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------ | :---------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------------- |
| **R-01** | **ETB Missing from Primary Currency Engine**              | `config/currencies.json` completely omits ETB. `app/business/payments/currency.rb:60` lists ETB strictly as a secondary Stripe Connect payout currency. `app/javascript/utils/currency.ts:3` derives TypeScript types strictly from `currencies.json`. | Creators cannot price products in ETB; checkout crashes or defaults to USD; frontend currency selectors fail.                                     | High        | Add `"etb"` to `config/currencies.json` with `"symbol": "Br"`, `"min_price": 1000`. Verify `MoneyFormatter.format(1000, :etb)` renders `"10.00 Br"` without warnings. | Phase 1 (Foundation)    |
| **R-02** | **Stripe/PayPal Hardcoding in Checkout Flow**             | `app/controllers/orders_controller.rb:58-75` (`#prepare`) expects Stripe ConfirmationTokens. `app/javascript/components/Checkout/PaymentForm.tsx` imports and renders only Stripe Elements, Apple Pay, and PayPal SDK.                                 | Ethiopian buyers cannot check out using local payment methods (Telebirr, CBE Birr, Chapa).                                                        | High        | Build `ChapaChargeProcessor` implementing `ChargeProcessor` interface. Add Chapa redirect/modal checkout path to `PaymentForm.tsx`.                                   | Phase 1 (Payments)      |
| **R-03** | **Subscription Expiration Truncated on Early Payment**    | `Subscription#end_time_of_last_paid_period` in `app/models/subscription.rb:1234-1236` calculates `last_successful_not_reversed_or_refunded_charge_at + period`.                                                                                        | If a subscriber pays their monthly renewal 5 days before expiration, stamping `succeeded_at = Time.current` cuts 5 days off their previous cycle. | High        | Ensure renewal calculation anchors to `[end_time_of_subscription, Time.current].max + period` so customer never loses pre-paid days.                                  | Phase 2 (Subscriptions) |
| **R-04** | **Duplicate Subscription Renewal via Webhook Race**       | `RecurringChargeWorker` assumes off-session card pulls; manual Chapa webhook can arrive simultaneously with buyer browser return redirect.                                                                                                             | Single renewal payment could extend subscription twice (e.g. adding 2 months for 1 month's fee).                                                  | Medium-High | Wrap renewal execution in `subscription.with_lock`, enforce uniqueness on `chapa_tx_ref`, and guard against redundant extensions for the same cycle.                  | Phase 2 (Subscriptions) |
| **R-05** | **Admin Payout API Rejects Non-Stripe/PayPal Rails**      | `Api::Internal::Admin::PayoutsController#issue` (`app/controllers/api/internal/admin/payouts_controller.rb:100`) enforces: `unless PayoutProcessorType.all.include?(processor_param) return error "must be stripe or paypal"`.                         | Administrators cannot issue manual or bank payouts for Ethiopian creators via the admin API.                                                      | High        | Add `MANUAL` / `ETHIO_BANK` to `PayoutProcessorType.all` (`app/business/payments/payouts/payout_processor_type.rb`) or provide CSV batch export action.               | Phase 2 (Payouts)       |
| **R-06** | **TaxJar API Failure on Domestic Ethiopian Orders**       | `app/models/purchase_sales_tax_info.rb`, `app/services/taxjar_service.rb` expects US/EU address structures and external TaxJar credentials.                                                                                                            | Checkout raises unhandled API exceptions or applies foreign sales tax rules to Ethiopian purchases.                                               | Medium      | Bypass TaxJar calculation when buyer country is Ethiopia (`country == "ET"`). Apply native flat Ethiopian VAT (15%) or zero-rate.                                     | Phase 1 (Checkout)      |
| **R-07** | **Postal Zip Code Validation Blocks Ethiopian Buyers**    | `app/models/purchase_address.rb` and `app/javascript/components/Checkout/PaymentForm.tsx:48` enforce postal code presence.                                                                                                                             | Ethiopian buyers (who do not use postal zip codes) encounter form validation blocking order submission.                                           | High        | Make `zip_code` optional for Ethiopian addresses or default to `"1000"` in checkout normalization.                                                                    | Phase 1 (Checkout)      |
| **R-08** | **Ethiopic Glyphs Render as Tofu Blocks**                 | `app/javascript/stylesheets/_font.scss:1-24` defines only `ABC Favorit`, which lacks Ethiopic Unicode characters (`U+1200..U+137F`).                                                                                                                   | Amharic text appears broken, inconsistent, or as unrenderable square boxes (tofu) on Android/Linux.                                               | High        | Add `Noto Sans Ethiopic` to web font declarations and prepend to Tailwind CSS font-family stacks.                                                                     | Phase 1 (UI/Font)       |
| **R-09** | **Hardcoded USD Earnings Gates Block Seller Features**    | `User#eligible_for_store_agent?` (`app/models/user.rb:1533`) and `eligible_for_ai_product_generation?` (`line 1519`) require `sales_cents_total >= 10_000` ($100 USD).                                                                                 | Ethiopian sellers with hundreds of thousands of Birr in sales remain blocked from earned-access features due to USD currency mismatch.            | Medium      | Evaluate thresholds against seller default currency or convert ETB cents using exchange rate helper.                                                                  | Phase 3 (Advanced)      |
| **R-10** | **Uncontrolled USD API Bills from AI Features**           | `Ai::AnthropicClient` (`app/services/ai/anthropic_client.rb`) defaults to `claude-opus-4-7` with 25-turn loop and 20,000 character prompt window.                                                                                                      | Platform incurs heavy foreign-currency API expenses (payable in USD) while collecting revenue in non-convertible ETB.                             | High        | Feature-flag off `store_agent_*` and generative AI endpoints globally via `Feature.deactivate(...)`.                                                                  | Phase 1 (Launch)        |
| **R-11** | **Elasticsearch Index Failure Stalls Marketplace Search** | `Link.search` (`app/controllers/concerns/search_products.rb:10-14`) requires an active, connected Elasticsearch cluster (`config/initializers/elasticsearch.rb`).                                                                                      | `/discover` and search autocomplete return 500 errors if Elasticsearch is misconfigured or down.                                                  | Medium      | Verify Elasticsearch is provisioned in docker-compose / staging environment and indexes are seeded with `Link.reindex`.                                               | Phase 1 (Marketplace)   |
| **R-12** | **External SMS Delivery Absent for Ethiopian Networks**   | Gumroad relies strictly on email notifications (SendGrid / Resend). In Ethiopia, mobile Internet latency makes SMS critical for payment reminders.                                                                                                     | Buyers miss subscription renewal notices or order delivery receipts if they do not check email regularly.                                         | Medium      | Add domestic SMS gateway integration (Ethio Telecom / Safaricom) for order receipts and renewal reminders.                                                            | Phase 2 (Notifications) |
